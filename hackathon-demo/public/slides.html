DEVNET · NO REAL MONEY

Pay for freelance work without moving the goalposts.

A client hires a freelancer for one deliverable. The client fears paying for work that only looks done. The freelancer fears the standard moving after delivery.

The live sample is Northwind Coffee hiring a writer for a homepage headline.

02 · THE PRODUCT

Freeze done before work. Lock the reward. Let Solana settle once.

Northwind Coffee writes the job and locks 0.05 practice SOL before the writer starts. After that, the agreed headline cannot be edited.

A short line is not paid. The agreed line is paid once. Paying again is rejected.

03 · WHY SOLANA

The pay is not a row in a database.

  • Escrow is SOL in an account the program owns.
  • The frozen “done” rule is a hash on the intent account, not text the website can change later.
  • Settlement is the program paying that escrow once. A server message is not the payment.
